# KN-COMM-002 · Narrative as a Tool · 叙事作为工具

- knowledge_type: presentation_principle
- evidence_grade: B
- source_ids: [SRC-DUARTE-2010, SRC-ATKINSON-2005, SRC-GALLO-2010]
- last_reviewed: 2026-09

## Core claim
叙事（Character→Goal→Conflict→Change→Meaning；或 What is / What could be 对比节奏）提升情感卷入与记忆，但它是工具，不是默认值。

## 适用
Persuasion / Vision / Transformation / Case Study / Emotional Engagement / Pitch / Product Launch。

## 不一定适用
Audit / Technical Reference / Operational Checklist / 合规报告——这些场景叙事会稀释效率甚至显得回避问题。

## Mechanism（假设性）
叙事提供因果结构，降低"这些信息如何关联"的组织成本；冲突-解决结构维持注意（开放环路）。

## Boundary conditions
- 时间极短的 Executive Briefing：SCQA/结论先行优于完整叙事弧。
- 叙事不得替代证据：故事是证据的载体，不是证据本身。
