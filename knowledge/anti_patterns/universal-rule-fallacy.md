# KN-ANTI-001 · Universal Rule Fallacy · 通用规则谬误

- knowledge_type: anti_pattern
- evidence_grade: —（元原则）
- last_reviewed: 2026-09

## 表现
把语境启发当成普适规则："每页最多 6 行""每行最多 6 字""标题必须是问句""字越少越高级""动画越少越好""一页只能一个观点/一张图""永远不能用表格/3D"。

## 为什么是谬误
这些命题全部缺少 Mechanism / Context / Evidence / Boundary / Exception 五要素。它们的合理内核只在特定语境成立：
- "一页一个观点" ≈ "每个 Scene 一个 Cognitive Job"（降低并行加工）——但 Reader Mode 与高密度技术幕例外。
- "字越少越好" ≈ Stage Mode 的 Redundancy 原则——但 Reader Mode 必须完整。
- "动画越少越好" ≈ Minimum Sufficient Motion——但因果/流程场景动画显著提升理解。

## 处理规程
1. 识别规则的合理内核（对应哪个机制节点）。
2. 登记为 Contextual Heuristic 或 Practitioner Hypothesis。
3. 标注适用语境与边界后使用；用户强推普适化时，引用本节点说明。
