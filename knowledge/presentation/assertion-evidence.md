## 结构
```
Assertion Headline（一句话断言，陈述本幕结论）
+
Visual Evidence（图/数据/照片/示意图，而非项目符号列表）
```

## 实验效果（SRC-GARNER-ALLEY-2013 全文验证，N=110 工程本科生）
- 论文式开放回答总分 **d=0.81**（p<.001）；延迟一周复测 **d=0.89**——优势保持。
- 五个内容子节四个显著（d=0.82/0.39/0.46/0.34）；动态因果表达 d=0.60。
- 误解总数减少 d=0.47；感知心智努力更低 d=-0.50。
- 即时选择题仅高阶推理/模拟题显著（η²=.09）；**事实回忆无组间差异**——优势在理解迁移，不在死记。
- 词数对照：CP 41.5 词/页 vs AE 21.2 词/页，旁白相同。
- 边界：验证于工程/技术内容与教学情境；对营销、情感动员、纯叙事场景的适用性证据不足。
- 与 Question Headline 的关系：受众无问题意识时用 Question 拉起缺口，随后用 Assertion 收口——两者是序列关系，不是对立关系。

## Presentation implications
- 技术/科研/数据/咨询演示默认评估 Assertion-Evidence 是否适用。
- assertion 必须是可证伪的陈述句，不是话题标签（"市场分析" ❌ → "华东市场增长已停滞两个季度" ✓）。
- 证据必须可挂 evidence_scene（现场被质疑时跳转）。
