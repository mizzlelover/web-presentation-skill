# KN-PRES-004 · Assertion-Evidence Structure · 断言-证据结构

- knowledge_type: presentation_principle
- evidence_grade: A（技术/科研演示语境）；其他语境 B–C
- source_ids: [SRC-ALLEY-2003, SRC-ALLEY-2006-AE, SRC-GARRETT-2016]
- last_reviewed: 2026-09

## 结构
```
Assertion Headline（一句话断言，陈述本幕结论）
+
Visual Evidence（图/数据/照片/示意图，而非项目符号列表）
```

## 实验效果（记录条件与边界）
- 在技术/科研演示实验中：理解测试得分与延迟回忆均优于传统"短语标题+项目符号"结构。
- 边界：验证于工程/科研受众与技术内容；对营销、情感动员、纯叙事场景的适用性证据不足。
- 与 Question Headline 的关系：受众无问题意识时用 Question 拉起缺口，随后用 Assertion 收口——两者是序列关系，不是对立关系。

## Presentation implications
- 技术/科研/数据/咨询演示默认评估 Assertion-Evidence 是否适用。
- assertion 必须是可证伪的陈述句，不是话题标签（"市场分析" ❌ → "华东市场增长已停滞两个季度" ✓）。
- 证据必须可挂 evidence_scene（现场被质疑时跳转）。
