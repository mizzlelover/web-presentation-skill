# KN-COG-002 · Cognitive Load Theory · 认知负荷理论

- knowledge_type: scientific_mechanism
- evidence_grade: A
- source_ids: [SRC-SWELLER-1988, SRC-MAYER-HANDBOOK-2014]
- last_reviewed: 2026-09

## Definition
认知负荷 = 内在负荷（材料本身复杂度 × 受众先备知识）+ 外在负荷（呈现方式造成的额外加工）+ 相关负荷（促进图式建构的加工）。

## Core claim
设计能改变的是外在负荷：去掉与 Cognitive Job 无关的元素，把负荷预算留给核心论证。

## Mechanism
工作记忆容量恒定，外在负荷每多一分，可用于理解论证的资源就少一分。

## Boundary conditions
- 专家受众的内在负荷低，可承受更高密度（expertise reversal effect：对新手有效的简化对专家反而有害——如把已整合的信息再拆开）。
- "负荷低"≠"好"：相关负荷（必要的认知努力）促进学习，教学型演示不应把一切都嚼碎。

## Presentation implications
- 认知负荷曲线：整场演示标注每幕 LOW/MEDIUM/HIGH/VERY_HIGH，禁止连续 HIGH 无缓冲。
- 节奏模式：Concept → Example → Data → Story → Synthesis。
- 删元素的标准是"它服务于本幕 Cognitive Job 吗"，不是"它是不是字"。
