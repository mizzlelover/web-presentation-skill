# Workflow: Analyze Source Content — 源内容分析

## 输入
原始材料（Word/Markdown/长文/数据/提纲）+ 用户口述的目标/受众/场景约束。

## 步骤
1. **清点材料**：列出全部事实、数据、论点、结论；区分"材料说的"与"用户想表达的"。
2. **识别核心命题**：材料最终想让受众相信/做什么？写成一句话 Central Thesis 候选。
3. **标注证据强度**：每个数据/论断标注来源与强度（对应证据分级 A–E 思路）；发现 fake/无来源数据时标记，禁止照用（§91）。
4. **发现缺口**：论证链上缺什么证据？受众可能质疑什么？列入 likely_questions / objections。
5. **内容精炼检查**（§56）：Redundancy / Abstract Inflation / AI Repetition / Long Paragraph / Weak Claim / Overexplaining / Underexplaining。

## 输出
- 内容清单（事实/论点/证据/缺口）
- Central Thesis 候选（1–3 个）
- 待向用户确认的问题清单（仅限影响策略的决策点，不问细节）

## 禁止
- 禁止在此步开始想版式、配色、模板。
- 禁止默默删除材料中"不方便"的反证。
