# Workflow: Build Argument Map — 论证架构图

## 输入
Presentation Strategy。

## 步骤
1. 建立 Central Thesis → Claim → Evidence/Example/Counterargument → Recommendation 树（§20）。
2. **逐项六查**：Unsupported Claim / Logical Gap / Evidence Mismatch / Argument Jump / Duplicate Claim / Overclaim。发现问题先修论证，再往下走。
3. **结构工具选择**：评估 SCQA / Pyramid / 叙事弧 / Question→Data→Insight→Decision 等哪个适合当前情境（§21、§60–64）；记录选择与理由。禁止默认 SCQA。
4. **Q&A 预埋**：为每个核心 Claim 列 likely_questions 与 objections，标记将来挂 evidence_scene / backup_scene。
5. **认知负荷预排**：为每个 Claim 预估负荷（LOW/MEDIUM/HIGH/VERY_HIGH），若连续 HIGH，插入 Example/Story/Synthesis 缓冲或拆分。

## 输出
- Argument Map（树状文本或 Mermaid）
- 六查结果与修复记录
- 结构工具选择 + 理由
- Q&A 预埋清单

## 禁止
- 禁止带着 Unsupported Claim 进入 Scene 规划（除非显式标记为"待补证据"并告知用户）。
