数据压力测试（补丁 §41）

用生产图表运行时 runtime/visualization/charts.js 直面六类数据压力：20 分类长中文标签、缺失值、正负混合、多单位双轴、小数百分比、极值与单位换算。逐项记录「能渲染 / 渲染失真 / 需要补能力」。

S120 分类 + 长中文机构名称（ranking）

要求：标签可读、不重叠、不截断成乱码。

S2缺失值（line，含 null）

要求：null 处断线而非补零；图例与 tooltip 正常。

S3正负混合 + 参照零线（bar）

要求：零轴可见，正负方向一目了然。

S4多单位双轴（bar + line，万元 vs %）

要求：两个系列不同量纲时不得挤成一条直线；右轴有独立单位。

S5小数百分比（bar，0–3%）

要求：不取整为 0/1；小数位可读。

S6极值跨度（1 → 98 万，pie 不适用 → bar）

要求：小值不消失；tooltip 显示原始值。
