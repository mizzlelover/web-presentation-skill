# METHODOLOGY — 演示方法论总纲

## 第一原则（§101）

| 原则 | 含义 |
|---|---|
| Audience before Author | 先回答"为什么这个人要听" |
| Goal before Layout | 先明确沟通目标动词 |
| Argument before Slides | 先有论证树，再拆 Scene |
| Cognitive Job before Visual | 先定每幕认知任务 |
| Evidence before Rule | 规则须有机制/语境/证据/边界/例外 |
| Context before Heuristic | 经验只在特定语境成立 |
| Structure before Decoration | 先结构后视觉 |
| Visual Meaning before Visual Beauty | 视觉首先承担信息 |
| Motion must Explain | 动效必须有 Intent |
| Interaction must Reduce Cognitive Cost | 交互必须降低理解成本 |
| Minimum Sufficient Rendering | 最低充分技术层级 |
| Web-native, not Web-decorated | 用 Web 本身，不模仿 PPT |
| Presentation is a Runtime | 演示是运行过程 |
| Presentation is Adaptive | 支持现场改路径 |
| One Content Model, Multiple Modes | Stage/Reader/Print 共享内容模型 |
| Scientific Evidence + Professional Practice | 证据与经验分层进入 |

## 决策链条（§5）

任何设计决策可沿链条追溯：`Situation → Audience → Goal → Cognitive State → Argument → Narrative → Mode → Density → Visual → Interaction → Motion → Rendering → Runtime → Delivery → Feedback → Adaptation`。上游变了，下游全部重估。

## 证据工作法（§2/§13）

1. 用户经验 → 登记 Practitioner Hypothesis（schemas/practitioner_hypothesis.yaml）。
2. 寻找 supporting / conflicting / boundary / alternative explanations。
3. 检验后升级（validated → 可升为 knowledge node）或标注 contextual/contradicted。
4. 引用优先级：Meta-analysis > Systematic Review > 原始实验 > 综述 > 权威专著 > 实践资料。
5. 证据分级 A–E；重要推荐默认只用 A/B/C。
